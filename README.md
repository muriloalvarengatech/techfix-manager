# TechFix Manager

Sistema de gerenciamento para uma empresa fictícia de assistência técnica de equipamentos eletrônicos, desenvolvido como parte do Projeto Integrado Multidisciplinar (PIM) do curso de Análise e Desenvolvimento de Sistemas.

## Sobre o projeto

O TechFix Manager tem como finalidade centralizar e organizar os processos de uma assistência técnica, desde o cadastro de clientes e equipamentos até a abertura de ordens de serviço, realização de diagnósticos, elaboração de orçamentos, controle de estoque, pagamentos e entrega dos equipamentos.

A proposta é reduzir a desorganização das informações, facilitar o acompanhamento dos serviços e melhorar o controle das atividades da empresa.

## Objetivos

- Centralizar os dados de clientes e equipamentos.
- Registrar e acompanhar ordens de serviço.
- Controlar diagnósticos e orçamentos.
- Gerenciar peças e movimentações de estoque.
- Registrar pagamentos e entregas.
- Manter o histórico dos serviços realizados.

## Tecnologias

- **Linguagem:** C
- **Ambiente de desenvolvimento:** Dev-C++
- **Armazenamento:** banco de dados relacional, com SGBD a definir.
- **Interface:** terminal (CLI).
- **Versionamento e documentação:** Git e GitHub.
- **Organização das tarefas:** Trello.

## Metodologia de trabalho

O desenvolvimento será organizado em Sprints semanais, com acompanhamento das tarefas pelo Trello, documentação e versionamento pelo GitHub e reuniões semanais para avaliação do progresso, identificação de impedimentos e alinhamento da equipe.

Todos os integrantes contribuirão com desenvolvimento, testes e documentação, conforme as responsabilidades definidas para cada Sprint.

## Organização do repositório

A estrutura será ampliada progressivamente conforme as necessidades do projeto.

- `docs/`: documentação técnica e acadêmica.
- `src/`: código-fonte em C.
- `tests/`: testes do sistema.
